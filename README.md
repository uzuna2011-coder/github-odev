README Dosyası Nedir ve Ne İşe Yarar?
Bir proje hakkında bilgi veren dosyadır. Projenin nasıl kurulup kullanılacağını açıklar.


Proje Versiyon/Sürümleri Nedir, Nasıl Belirlenir?
Proje sürümleri bir projenin geliştirilirken aldığı farklı versiyonlardır. Sürümler yapılan değişikliklerin eklenen özelliklerin ve düzeltilen hataların durumuna göre belirlenir.
